> 5. 子文件夹从 v2 的 5 个扩到 **7 个**:在 E_采训推 之外,新增 `F_envs/`(conda 环境管理)和 `G_algo/`(顶层算法入口)。

# 代码组织形式

> **本节是跨阶段稳定骨架**。三个阶段都共用这一节定义的组织形式,不允许在阶段间破坏它。

## 8 大子文件夹职责

```
padp-vla/
├── A_common/   (A_通用)        工具/类型/接口契约/注册表/IPC/日志/测试 — 不属于任何具体业务
├── B_model/    (B_模型)        模型架构(encoders / networks / adapters / compose)
│   ├── encoders/                5 类独立编码器
│   ├── networks/                核心主干(DM / FM / VLM)
│   ├── adapters/                接入市面 VLA 的适配层
│   └── compose/                 组装层 + base_policy 接口
├── C_sim/      (C_仿真)         仿真环境 + adapter
├── D_real/     (D_真机)         真机硬件接入
├── E_cti/      (E_采训推)       采/训/推 入口与配置
├── F_envs/     (F_环境)         conda 环境管理(集中)
└── G_algo/     (G_算法)         顶层算法/模型实例化入口 + Pipeline
```

| 字母 | 性质 | 改动频率 | 跨阶段稳定性 |
|---|---|---|---|
| **A_common** | 横向基础设施 | 低 | ✅ 跨阶段稳定 |
| **B_model** | 模型本身 | 高(消融、加新模型) | ⚠️ 内容变化大,**接口契约稳定** |
| **C_sim** | 仿真专属 | 中(加 sim 时改) | ⚠️ 阶段 1 / 2 简单,阶段 3 扩展 |
| **D_real** | 真机专属 | 中(换硬件时改) | ❌ 阶段 1 不启用,阶段 2+ 启用 |
| **E_cti** | 业务流程入口 | 中(参数 yaml 改) | ✅ 结构稳定,内容随阶段增加 |
| **F_envs** | conda 环境管理 | 低 | ⚠️ 阶段 1 简单,阶段 2+ 全套 |
| **G_algo** | 顶层算法入口 | 中(加新算法时改) | ⚠️ 阶段 1 = DP/PADP,阶段 2+ 加 SDP 等 |

from dataclasses import dataclass
import torch

@dataclass
class ActionOutput:
    """统一的模型输出,抹平 step vs chunk 的差异。

### 契约 2:`BaseVLAPolicy` 抽象基类

**位置**:`B_model/compose/base_policy.py`

```python
from abc import abstractmethod
from typing import Dict, Optional
import torch
import torch.nn as nn
from A_common.types.action_output import ActionOutput

class BaseVLAPolicy(nn.Module):
    """所有 policy 的统一接口。采/训/推外围代码只跟这个接口打交道。
    
    实现:
        - 阶段 1: PADPDiffusionPolicy(基于 UNet1D + position-aware loss)
        - 阶段 2: 同上(加上真机微调流程)
        - 阶段 3: OpenVLAAdapterPolicy, OctoAdapterPolicy, FlowMatchingPolicy 等
    
    调用方不需要知道具体是哪个实现,只看 `predict_action` 返回的 ActionOutput。
    """
    
    def __init__(self):
        super().__init__()
        self._normalizer = None  # 由 set_normalizer() 注入
    
    @abstractmethod
    def predict_action(
        self,
        obs_dict: Dict[str, torch.Tensor],
        prompt: Optional[str] = None,
    ) -> ActionOutput:
        """从 obs 推理动作。
        
        Args:
            obs_dict:  {"rgb": tensor, "state": tensor, ...} 任意字段
            prompt:   自然语言指令(可选)
        
        Returns:
            ActionOutput(actions, is_chunk, latency_ms)
        """
        raise NotImplementedError
    
    @abstractmethod
    def compute_loss(
        self,
        batch: Dict[str, torch.Tensor],
    ) -> torch.Tensor:
        """训练阶段用,返回 scalar loss。"""
        raise NotImplementedError
    
    def reset(self) -> None:
        """推理 episode 切换时清空状态(流式 / chunk 类策略需要)。"""
        pass
    
    def set_normalizer(self, normalizer) -> None:
        """训练完后注入 normalizer,推理时自动用其反归一化。"""
        self._normalizer = normalizer
```

### 契约 3:`policy_registry` 注册表

**位置**:`B_model/compose/policy_registry.py`

```python
from typing import Dict, Type
from B_model.compose.base_policy import BaseVLAPolicy

_POLICY_REGISTRY: Dict[str, Type[BaseVLAPolicy]] = {}

def register_policy(name: str):
    """装饰器:把 Policy 类注册到 name 下面。"""
    def decorator(cls: Type[BaseVLAPolicy]) -> Type[BaseVLAPolicy]:
        if name in _POLICY_REGISTRY:
            raise ValueError(f"Policy {name} already registered")
        _POLICY_REGISTRY[name] = cls
        return cls
    return decorator

def build_policy(config: dict) -> BaseVLAPolicy:
    """工厂:从 config 字典实例化 policy。"""
    name = config["name"]
    if name not in _POLICY_REGISTRY:
        raise KeyError(f"Unknown policy: {name}. Available: {list(_POLICY_REGISTRY)}")
    return _POLICY_REGISTRY[name](**config.get("kwargs", {}))

def list_policies() -> list[str]:
    return list(_POLICY_REGISTRY.keys())
```

# PADP v3 — 第一阶段:复现 square 90%

## 阶段目标

- **核心目标**:在 `square` 仿真任务上,**复现 PADP 当前推理成功率 ≥ 90%**
- **次要目标**:跑通 baseline DP(标准扩散策略)做对照,确认新架构不引入回归
- **不做的事**:不做真机、不做多 sim 混训、不做其他 VLA、不做 VLM

## 启用子模块

| 子文件夹 | 启用内容 |
|---|---|
| A_common | types(action_output, observation, state)+ registry |
| B_model | encoders(VM/AM/LM/TM)+ networks/DM(UNet1D PADP)+ compose |
| C_sim | robomimic(square_d0 / can / lift 三个先打通)+ pusht + kitchen |
| D_real | ❌ 不启用 |
| E_cti | 训 / 推(暂时不需要采) |
| F_envs | 单 sim-robomimic 简单 env,只够跑 3 个 task |
| G_algo | DP/(baseline)+ PADP/ |

## 关键节点与验收

| 节点 | 目标 | 验收 |
|---|---|---|
| **1.1 契约就位** | 4 个契约 + 3 个 AI 提示词生成骨架 | `A_common/types/*` + `B_model/compose/{base_policy,policy_registry}.py` 可 import,pytest 通过 |
| **1.2 UNet1D + Position-aware loss** | 复现 PADP 的 1D Conditional UNet + per-position weight | 在 square_d0 单 task 上训 100 epoch,eval ≥ 90% 成功率(对照 PADP 现状) |
| **1.3 Baseline DP** | 跑通标准 Diffusion Policy(无 position-aware) | 单 task 成功率与 PADP 原版 ≤ 3% 差距(确认迁移没引入回归) |

| **1.5 阶段 1 收尾** | 训练 + eval 流程文档化 | README + 命令清单 + 已知问题 |

## 加新模型/新臂的标准流程

> **本节是阶段 3 的"操作手册"**。后续往仓库加任何新模型、新机械臂,按这个流程,外围代码完全不动。

### 加新算法(如新 diffusion variant)

1. 在 `B_model/networks/<新>/` 实现网络 + scheduler + loss
2. 在 `B_model/compose/<新>_policy.py` 写 Policy 类,继承 `BaseVLAPolicy`,加 `@register_policy("<name>")`
3. 在 `G_algo/<新>/pipeline.py` 写训练 / 评估入口
4. 加一份 `E_cti/训/配置/<新>.yaml`

### 加新 VLA(走 adapters)

1. 在 `B_model/adapters/<新>.py` 写 Adapter,继承 `BaseVLAPolicy`,加 `@register_policy("<name>")`
2. 适配:把官方 VLA 的输入/输出格式转成统一 `Observation` / `ActionOutput`
3. 加一份配置 yaml

### 加新机械臂

1. 在 `D_real/<新臂>/` 写 `controller.py`(SDK 适配)+ `interpolation.py`(频率适配)+ `state_reader.py` + `adapter.py`
2. 加一份 `F_envs/` 下的 conda yaml
3. 在 `E_cti/采/real_collect/` 加采集脚本

### 加新仿真

1. 在 `C_sim/<新 sim>/` 写 `env_impl/env_runner/adapter/conda.yaml`
2. 在 `E_cti/采/to_lerobot/` 加 `*_to_lerobot.py` 转换脚本
3. 加一份 `E_cti/训/配置/<新 sim>.yaml`
