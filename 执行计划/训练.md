## 跑法 3: 训练时启用 rollout (双协议, env_server 你手起)

> Train 进程内 spawn **policy_server + client**,env_server 走外部
> (你已手起,所以 `env_server.spawn: false`)。
> 跑法 1 训完每个 epoch (按 `rollout_every`) 自动起一次 policy_server+client,
> client 同时连外部 env_server, 算 test_mean_score。
> 这是源端 `train_padp_workspace.run()` 696-718 行的 VLA 复刻(双协议版)。

### Step 1: 编辑 yaml, 把 rollout 打开

```yaml

  skip_rollout: false       # ← 改 false (默认 true)
  # ...

  enabled: true             # ← 改 true (默认 false)
  rollout_every: 1          # 每 1 epoch 跑一次
  n_test: 5                 # 跑 5 episode
  max_steps: 400

  env_server:
    spawn: false                                        # ← 关键: 不 spawn,连外部
    external_host: 127.0.0.1
    external_port: 8766
    config_name: robomimic_padp_position_wise_v3_env_v6
    config_dir: /media/disk7t/PADP_v3/diffusion_policy/config
  # policy_server: train 进程内 spawn
  policy_server:
    spawn: true                                         # ← train 内部 spawn
    host: 127.0.0.1
    port: 8765

    spawn: true                                         # ← train 内部 spawn
```

### 双协议 client 的关键设计点(给实现者看)

```
client 进程
  │
  ├─── WebSocket ──→  ws://127.0.0.1:8766  (PADP 源端 serve_env_v6)
  │                  msgpack_numpy 协议
  │                  调用 EnvClientPolicy 接口:
  │                    - setup_envs(args_list)   ← 一次,dill 函数
  │                    - reset() → obs
  │                    - step(action) → obs, reward, done
  │                    - close()
  │
  └─── TCP ───────→  127.0.0.1:8765       (VLA 端 padp_for_test_server)
                     msgpack + 4B 长度前缀
                     调用 padp_for_test_protocol 接口:
                       - EP_CHANGE → RESET_ACK  (新 episode 触发 reset)
                       - OBS → ACTION           (action = [D_a])
                       - EP_END                 (上报 success)
                       - PING / PONG            (心跳)
```

**核心 loop** (per step):
```python
obs = env_client.reset()                              # WS: 拿 obs
send_framed(policy_sock, pack_ep_change())            # TCP: 通知 policy 新 ep
ack = recv_framed(policy_sock)                        # TCP: 等 RESET_ACK
while not done:
    send_framed(policy_sock, pack_obs(obs))           # TCP: 发 obs
    resp = recv_framed(policy_sock)                   # TCP: 收 action
    obs, reward, done, info = env_client.step(action) # WS: 推 env
    send_framed(policy_sock, pack_ep_end(ep, success))# TCP: ep 边界(可选)
```
