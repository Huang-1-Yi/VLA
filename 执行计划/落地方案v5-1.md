# 落地方案v5-1 — 阶段 1 实施手册(Fat Policy + 5 接口契约,~65 文件)

> **本文件是 [落地方案v5.md](落地方案v5.md) 架构规范下的阶段 1 实施手册**(v5 + 1 = 实施层)。
>
> **配套文档**:
> - 上位架构:[落地方案v5.md](落地方案v5.md) — 7-Layer + 7 铁律强化版 + 5 接口契约总览
> - **5 个接口契约模板**:[落地方案v4-1的接口契约.md](落地方案v4-1的接口契约.md)(权威,本文件只引用)
> - 历史(已废):[落地方案v4.md](落地方案v4.md) / [落地方案v4-1.md](落地方案v4-1.md)
>
> **代码组织原则(v5,本阶段必守)**:
> 1. `E_cti` 不许写 `class`,只写执行脚本;E_cti 是"纯白痴",**只能调 `policy.compute_loss(batch)` 和 `policy.predict_action(obs)`**(铁律 1 强化版)
> 2. `B_model` 只放**纯算力零件**(Encoders/Networks/Adapters);**Policy 类归 `Gpolicy/<algo>/<algo>_policy.py`**(继承 `BasePolicy`,**Fat Policy**);**不定义 Policy 类**
> 3. 数据结构 + 5 个协议/接口抽象一律进 `A_common/types/`(铁律 3,含 `BasePolicy` / `VisionEncoderInterface` / `ActionEncoderInterface` / `TimestepEncoderInterface` / `DiffusionNetworkInterface`)
>
> **本版相对 v4-1 旧版的根本差异**(v5 重构后):
> 1. **Policy 类从 `B_model/compose/` 整体迁出**(v4 旧版的 `B_model/compose/{base_policy, padp_policy, dp_policy, fusion}.py` 全部不存在)
> 2. **Policy 类升格为 Fat Policy**:在 `__init__` 里**实例化** Adapter + TM + DM,还**一次性实例化** `self.train_scheduler` / `self.infer_scheduler` / 缓存 `self.horizon` / `self.action_dim`;暴露 3 个必须方法(`forward` + `compute_loss` + `predict_action`)
> 3. **B_model 新增 `adapters/` 子目录**:每个算法一个 `<algo>_adapter.py`,Adapter 内部实例化 VM/AM 并做特征融合
> 4. **A_common 新增 5 个接口契约文件**:`vision_encoder.py` / `action_encoder.py` / `timestep_encoder.py` / `diffusion_network.py` / `base_policy.py`
> 5. **E_cti 变成"纯白痴执行台"**:训练 loop 唯一动作 `loss = policy.compute_loss(batch)`,推理 loop 唯一动作 `action = policy.predict_action(obs)`,**不知道 scheduler / 加噪 / loss 是什么**
> 6. 文件数预估 **60 → ~65**(+5 接口契约、+adapter 目录、+新增测试)

## 一、阶段 1 目标与范围

**核心目标**:在 `square` 仿真任务上,**复现 PADP 当前推理成功率 ≥ 90%**。

**次要目标**:跑通 baseline DP 做对照,确认新架构不引入回归。

**不做的事**:不做真机、不做多 sim 混训、不做其他 VLA、不做 VLM、不做 Flow Matching。

**阶段 1 启用**:
- 训练:ResNet18(VM) + Conv1d embed(AM) + Sinusoidal(TM) + 1D Conditional UNet(DM) + FeatureFusionMLP(Adapter) + SlidingWindowDiffusionPolicy(Fat Policy)
- 仿真:robomimic(只 `square_d0` / `can` / `lift`,其他 sim 占位)
- 评估:`square_d0` 必须跑,`can` / `lift` 二选一
- 暂不启用:LM / dinov2 / transformer / 真机 / Flow Matching / OpenVLA / 第三方 VLA

**验收门槛**:
1. `square_d0` 单 task 成功率 ≥ 90%
2. DP baseline 跑通(差距 ≤ 3%)
3. 7-Layer 自动化检查脚本全 OK(10+ 行,含铁律 1 强化版 3 子条)

class SinusoidalTimestepEncoder(TimestepEncoderInterface):
    def __init__(self, d_h: int = 512):
        super().__init__()
        self.embed = SinusoidalPosEmb(d_h)
        self.mlp = nn.Sequential(nn.Linear(d_h, d_h*4), nn.SiLU(), nn.Linear(d_h*4, d_h))

### 6.1 `Gpolicy/common/denoise_loop.py` — 共享 DDIM 推理模板

> **铁律 5 体现**:`scheduler` 作为参数注入,不硬编码

**关键**:
```python
@torch.no_grad()
def denoise_loop(policy: BasePolicy, global_cond: torch.Tensor, scheduler,
                 horizon: int, action_dim: int,
                 normalizer=None) -> torch.Tensor:
    """DDIM 推理 denoise loop。policy 必须是 register 过的实例。
    scheduler 由调用方(PADP/DP 的 predict_action)注入,本函数不做任何
    scheduler 的实例化。sched 协议:
        - scheduler.timesteps:  可迭代的 long tensor
        - scheduler.step(eps, t, a) -> 输出含 .prev_sample
    """
    a = torch.randn((global_cond.shape[0], horizon, action_dim),
                    device=global_cond.device, dtype=global_cond.dtype)
    for t in scheduler.timesteps:
        t_batch = torch.full((a.shape[0],), t, device=a.device, dtype=torch.long)
        eps = policy.forward(a, t_batch, global_cond)
        a = scheduler.step(eps, t, a).prev_sample
    if normalizer is not None:
        a = normalizer.unnormalize(a, key="action")
    return a
```

**关键修正**:本文件**禁止** `from diffusers import DDIMScheduler` 或 `DDIMScheduler(...)` 调用。

**源**:参考 [PADP/diffusion_policy/policy/schedulers.py](PADP/diffusion_policy/policy/schedulers.py) 的 DDIMScheduler 协议

### 6.2 `Gpolicy/PADP/padp_policy.py` — **核心 Fat Policy(v7 强化)**

> **v7 强化要点**:
> 1. `__init__` 一次性实例化 `self.train_scheduler` + `self.infer_scheduler`
> 2. `__init__` 缓存 `self.horizon` + `self.action_dim`
> 3. 暴露 3 个必须方法:`forward` + `compute_loss` + `predict_action`
> 4. 内部循环外提 1 次特征(性能关键!)

**关键**:
```python
@register_policy("padp_unet")
class SlidingWindowDiffusionPolicy(BasePolicy):
    """PADP 位置感知扩散 Fat Policy。
    
    Args:
        cfg: 配置 dict,含 scheduler / policy / padp 三个子段
    """
    def __init__(self, cfg: dict):
        super().__init__()
        self.cfg = cfg

        # ===== 算力零件装配(B_model 组件)=====
        self.adapter = PADPAdapter(cfg)  # B_model/adapters/padp_adapter.py
        self.tm = SinusoidalTimestepEncoder(cfg.tm.d_h)  # B_model/encoders/TM/
        self.denoiser = Unet1DPadp(...)  # B_model/networks/DM/

        # ===== 调度器一次性实例化(v7 Fat Policy 设计)=====
        self.train_scheduler = DDIMScheduler(
            num_train_timesteps=cfg.scheduler.num_train_timesteps,
            beta_schedule=cfg.scheduler.beta_schedule,
            ...
        )
        self.infer_scheduler = DDIMScheduler(
            num_train_timesteps=cfg.scheduler.num_train_timesteps,
            beta_schedule=cfg.scheduler.beta_schedule,
            ...
        )

        # ===== 维度缓存(供 predict_action 初始噪声用)=====
        self.horizon = cfg.policy.horizon
        self.action_dim = cfg.policy.action_dim

        logger.info(self.shape_info())  # 调试时一眼看清装配

    def shape_info(self) -> str:
        return f"vm={self.adapter.vm.output_shape()}, am={self.adapter.am.output_shape()}, tm={self.tm.output_shape()}, dm={self.denoiser.output_shape()}"

    def forward(self, a_t: torch.Tensor, t: torch.Tensor,
                global_cond: torch.Tensor) -> torch.Tensor:
        """单步 DM 封装:被 compute_loss / predict_action 内部调用。"""
        encoded_t = self.tm(t)
        return self.denoiser(a_t, global_cond=global_cond, encoded_t=encoded_t)

    def compute_loss(self, batch: dict) -> torch.Tensor:
        """训练高层入口。E_cti 唯一动作:loss = policy.compute_loss(batch)"""
        # 1. 采 t / 加噪(复用 __init__ 实例化的 scheduler)
        a0 = batch["action"]  # [B, H, D_a]
        t = torch.randint(0, self.train_scheduler.config.num_train_timesteps, (a0.shape[0],), device=a0.device)
        noise = torch.randn_like(a0)
        a_t = self.train_scheduler.add_noise(a0, noise, t)
        # 2. 提特征(1 次,不在 loop 里)
        global_cond = self.adapter(batch["obs"])
        # 3. 调 DM 前向
        pred_noise = self.forward(a_t, t, global_cond)
        # 4. 加权 MSE(PADP 特有,per-horizon 权重 w 形状 [H],广播为 [1, H, 1])
        w = loss_weights.padp_loss_weights(self.horizon, decay=self.cfg.padp.decay, alpha=self.cfg.padp.alpha)
        # loss 公式:对 (B, H, D_a) 元素先平方,再与 w 广播相乘,最后 mean 出 scalar
        return ((pred_noise - noise) ** 2 * w[None, :, None]).mean()

    def predict_action(self, obs: dict) -> ActionOutput:
        """推理高层入口。E_cti 唯一动作:action = policy.predict_action(obs)"""
        import time; t0 = time.time()
        B = next(iter(obs.values())).shape[0]
        # 1. 循环外提 1 次特征(性能关键!)
        global_cond = self.adapter(obs)
        # 2. Denoise Loop(复用 __init__ 实例化的 scheduler)
        a = torch.randn(B, self.horizon, self.action_dim,
                        device=self.device, dtype=self.dtype)
        for t in self.infer_scheduler.timesteps:
            pred_noise = self.forward(a, t, global_cond)
            a = self.infer_scheduler.step(pred_noise, t, a).prev_sample
        # 3. 反归一化
        if self._normalizer is not None and "action" in self._normalizer:
            a = self._normalizer["action"].unnormalize(a)
        return ActionOutput(actions=a, is_chunk=True, latency_ms=(time.time()-t0)*1000)

    def reset(self):
        """状态清空(sliding window buffer,可选)。"""
        pass
```

**关键修正(v7 强化版)**:
- `__init__` 一次性实例化 scheduler(vs v6 在每个方法体内 new 一次)
- `__init__` 缓存 `self.horizon` / `self.action_dim`(供 predict_action 初始噪声)
- 3 个必须方法(forward / compute_loss / predict_action)
- 循环外提 1 次特征(性能关键)
- 248 行从 PADP `SlidingWindowDiffusionPolicy` 整体抄来,改接口对齐

def main():

        cfg = yaml.safe_load(f)

            "ema_state": ema.state_dict(),
