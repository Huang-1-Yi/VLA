## 4. 常见错误与对应处理

### 4.1 数据相关

| 错误信息 | 原因 | 处理 |
|---|---|---|
| `FileNotFoundError: square_d0_abs.hdf5` | 数据未准备 | 跑 §0.1 |
| `KeyError: 'agentview_image'` | shape_meta 字段名不匹配 | 查 PADP `condig/robomimic_padp_position_wise_v3.yaml` 里的 shape_meta |
| `OSError: [Errno 24] Too many open files` | num_workers 太多 | `E_cti/configs/*.yaml` 里 `num_workers: 4` 改成 `0` |

### 4.2 环境相关

| 错误信息 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'robomimic'` | conda env 没装上 | `conda install -c conda-forge robomimic==0.3.0` |
| `numpy 2.x compat error` | numpy 升级了 | `pip install "numpy<2.0"` |
| `libtinfo.so.6: cannot open shared object file` | conda 链接路径缺 | `conda install -c conda-forge ncurses` |
| `CUDA out of memory` | batch_size 太大 | 调 `E_cti/configs/train_padp.yaml` 的 `batch_size: 32` |

### 4.3 训练相关

| 现象 | 原因 | 处理 |
|---|---|---|
| loss 不下降,卡在 ~1.0 | 数据加载错 / 模型未初始化 | 验证数据集 1-2 样本能否出 batch;调 `lr: 5e-5` 试 |
| loss 下降但评估成功率 < 50% | 训练不够 / horizon 错 | 训练 500 epoch 试;确认 `horizon=40, n_action_steps=8` |
| 成功率 70-85% | window_exp_gamma 调优 | 试 0.1 / 0.3 / 0.4 |
| 成功率 85-90% 差一点点 | 训练延长 / LR 调小 | `num_epochs: 500`, `lr: 5e-5` |
| 推理 latency > 100ms | UNet 没编译 / batch_size=1 | 跑 `torch.compile(B_model.networks.DM.unet1d_padp)` |

### 4.4 7 铁律自检失败

| FAIL | 修复 |
|---|---|
| 铁律 1(无 class) | 删 `E_cti/*` 里的 `class Xxx`,改为 `if __name__` 内的局部函数 |
| 铁律 2(B_model 反向依赖) | 把 G_algo / E_cti 里的逻辑搬到 B_model 内部(应该没有) |
| 铁律 3(数据结构散落) | 把 `class Xxx` 移到 `A_common/types/` |
| 铁律 4(直接 import C_sim 内部) | 改用 `C_sim.make_xxx(cfg)` |
| 铁律 5(denoise_loop 硬编码) | scheduler 改参数传入 |
| 铁律 6(无 n_obs_steps/horizon) | 在 `BaseVLADataset` 派生类加 `self.n_obs_steps = n_obs_steps` |
| 铁律 7(有 requirements.txt) | 删 `requirements.txt`,合到 environment.yml |

## 7. Todo 清单自动同步(改了 Todo 怎么改代码)

> **本节专门回答**:"我改了 Todo 清单,如何让代码自动跟着改?"

### 7.1 核心工具:`VLA/scripts/sync_todo.py`

这个脚本做 **Todo ↔ 文件系统 diff**,自动识别 3 种情况:

| 状态 | 含义 | 处理 |
|---|---|---|
| `[X] missing in actual` | Todo 列了但 VLA 没建 | 需要新建 |
| `[WARN] extra in actual` | VLA 有但 Todo 没列 | 可能是合理(每个目录的 `__init__.py` 等),也可能是 Todo 漏了 |
| `[OK] 完美同步` | 双方一致 | 没事 |

### 7.2 用法

#### 7.2.1 跑一次同步检查

```bash
cd VLA
PYTHONIOENCODING=utf-8 python scripts/sync_todo.py
```

#### 7.2.2 看 JSON 输出(贴给 AI 友好)

```bash
PYTHONIOENCODING=utf-8 python scripts/sync_todo.py --json
```

#### 7.2.3 自动 stub 缺失文件(只创建空骨架)

```bash
PYTHONIOENCODING=utf-8 python scripts/sync_todo.py --apply-stub
```

每个 .py 缺失会创建一个含 `TODO` 注释的空文件,再让 AI 去填。

#### 7.2.4 退出码(用于 CI / pre-commit)

```bash
PYTHONIOENCODING=utf-8 python scripts/sync_todo.py
echo "Exit: $?"
# 0 = 完美 / 1 = 有 missing / 2 = 有 extra(警告)
```

### 7.3 完整工作流:**改 Todo 后,自动同步代码**

**第 1 步**:改 Todo 清单(在 IDE 里勾选 + 添加/删除/重命名)

**第 2 步**:跑 sync 看差异

```bash
cd VLA
PYTHONIOENCODING=utf-8 python scripts/sync_todo.py --json > /tmp/sync_report.json
cat /tmp/sync_report.json
```

**第 3 步**:把 sync 报告 + Todo diff 一起贴给 AI,让 AI 写新代码

> 见下面的"模板 G:Todo 改完后同步"

**第 4 步**:AI 写完代码后,再跑一次 sync 验证

```bash
PYTHONIOENCODING=utf-8 python scripts/sync_todo.py
```

预期:完美同步 `[OK]`。
