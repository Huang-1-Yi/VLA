## 3. B_模型 文件级映射

> **v4 重构后**,B_model 只放可复用网络部件(encoders / networks / adapters),**不再含 Policy 类**。
> 详细 v4 重构说明见 [v4 §1.3](落地方案v4.md#13-为什么-b_model-不再含-policy-类设计动机)。
> Policy 类(继承 BaseVLAPolicy)的映射见 [§3.9](#39-新加-policy-类映射v4-重构后)。

`B_模型` 下每个子模块统一约定:`interface.py` 定义抽象 + 输出 vector 的契约,具体实现并列存放。

### 3.1 VM 视觉编码器

| 新文件 | 来源 | 改造点 |
|---|---|---|
| `B_模型/VM/interface.py` | 新写 | 定义 `encode(rgb) -> [B, N_token, D_h]` 契约 |
| `B_模型/VM/dinov2.py` | 抄 [diffusion_policy/model/task_padp/dinov3_timm_obs_encoder.py](../../PADP/diffusion_policy/model/task_padp/dinov3_timm_obs_encoder.py) | 把 DINOv3 换 DINOv2-small/base;去掉 PADP 专用 obs dict 入口,改成统一 [B, N_cam, 3, H, W] |
| `B_模型/VM/siglip.py` | 参考 [src/openpi/models/siglip.py](src/openpi/models/siglip.py) | 只取 vision tower,适配 PyTorch |
| `B_模型/VM/resnet.py` | 抄 [diffusion_policy/model/vision/dp_multi_image_obs_encoder.py](../../PADP/diffusion_policy/model/vision/dp_multi_image_obs_encoder.py) | 保留 ResNet18 baseline 路径 |

### 3.2 AM 动作编码器

| 新文件 | 来源 | 改造点 |
|---|---|---|
| `B_模型/AM/interface.py` | 新写 | 定义 `embed(action_seq) -> [B, H, D_h]` |
| `B_模型/AM/conv1d_embed.py` | 抽 [diffusion_policy/model/diffusion/conv1d_components.py](../../PADP/diffusion_policy/model/diffusion/conv1d_components.py) | 把 UNet 入口的 Conv1d 抽出来独立,便于复用/消融 |
| `B_模型/AM/mlp_embed.py` | 新写 | 给 transformer 风格 denoiser 备选 |

### 3.3 LM 文本编码器

| 新文件 | 来源 | 改造点 |
|---|---|---|
| `B_模型/LM/interface.py` | 新写 | 定义 `encode(text) -> (tokens, pooled)` + 内置 LRU cache 钩子 |
| `B_模型/LM/clip_text.py` | 抽 [diffusion_policy/model/task_padp/multi_image_obs_encoder_clip.py](../../PADP/diffusion_policy/model/task_padp/multi_image_obs_encoder_clip.py) 的 text 部分 | 只留 text encoder,丢图像部分 |
| `B_模型/LM/t5_small.py` | 新写,基于 transformers | 备选,小模型友好 |

### 3.4 VLM 视觉语言联合编码器

| 新文件 | 来源 | 改造点 |
|---|---|---|
| `B_模型/VLM/interface.py` | 新写 | `encode(rgb, text) -> [B, N, D_h]`(联合 token 序列)|
| `B_模型/VLM/paligemma.py` | 参考 [src/openpi/models_pytorch/gemma_pytorch.py](src/openpi/models_pytorch/gemma_pytorch.py) + [src/openpi/models_pytorch/transformers_replace/models/paligemma/modeling_paligemma.py](src/openpi/models_pytorch/transformers_replace/models/paligemma/modeling_paligemma.py) | 4090 仅能装小尺寸 PaliGemma;**默认不启用,作为消融** |

### 3.5 TM 时间步编码器

| 新文件 | 来源 | 改造点 |
|---|---|---|
| `B_模型/TM/interface.py` | 新写 | `embed(t: [B]) -> [B, D_h]` |
| `B_模型/TM/sinusoidal.py` | 抄 [diffusion_policy/model/diffusion/positional_embedding.py](../../PADP/diffusion_policy/model/diffusion/positional_embedding.py) | 原文件 + 一个小 MLP head |

### 3.6 SM 状态编码器(可选)

| 新文件 | 来源 | 改造点 |
|---|---|---|
| `B_模型/SM/interface.py` | 新写 | `embed(state: [B, D_s]) -> [B, D_h]` |
| `B_模型/SM/mlp.py` | 新写 | 2-layer MLP,沿用 [diffusion_policy/model/common/modules.py](../../PADP/diffusion_policy/model/common/modules.py) 的 dropout/norm 风格 |

### 3.7 Denoiser 去噪模型

| 新文件 | 来源 | 改造点 |
|---|---|---|
| `B_模型/denoiser/interface.py` | 新写 | `forward(a_t, t_emb, context) -> ε̂`;`context` 是 fusion 层产出的统一向量包 |
| `B_模型/denoiser/unet1d_padp.py` | 抄 [diffusion_policy/model/diffusion/conditional_unet1d_padp.py](../../PADP/diffusion_policy/model/diffusion/conditional_unet1d_padp.py) | 去掉硬编码的 `global_cond_dim`,改成接收任意 `context`;加 cross-attn 入口可选位 |
| `B_模型/denoiser/loss_weights.py` | 抄 [diffusion_policy/policy/schedulers_padp.py](../../PADP/diffusion_policy/policy/schedulers_padp.py) 的 weight 部分 | per-position / per-step 加权曲线生成 |
| `B_模型/denoiser/transformer.py` | 参考 [diffusion_policy/model/diffusion/transformer_for_action_diffusion.py](../../PADP/diffusion_policy/model/diffusion/transformer_for_action_diffusion.py) | 备选 backbone,消融用 |

### 3.8 Compose 组装层(v4 重构后**已删除**整个目录)

> **v4 重构前**:
> | 新文件 | 来源 | 改造点 |
> |---|---|---|
> | `B_模型/compose/fusion.py` | 新写 | FiLM / cross-attn / concat 三种 fusion 实现,统一接口 |
> | `B_模型/compose/policy.py` | 抄 [diffusion_policy/policy/PADP_diffusion_unet_image_policy.py](../../PADP/diffusion_policy/policy/PADP_diffusion_unet_image_policy.py) 顶层结构 | 改为按 config 装配 VM/AM/LM/VLM/TM/SM/denoiser;`predict_action` / `compute_loss` 接口保留 |
>
> **v4 重构后**(本目录**整体迁出**,不再存在于 B_model):
> - `B_模型/compose/policy.py` → 拆为 3 文件:
>   - 抽象基类 → `A_common/types/base_policy.py`
>   - PADP 专属 Policy → `G_algo/PADP/padp_policy.py`
>   - DP 共享 Policy → `G_algo/DP/dp_policy.py`
> - `B_模型/compose/fusion.py` → `G_algo/common/fusion.py`
> 详见 [§3.9](#39-新加-policy-类映射v4-重构后)。

### 3.9 新加:Policy 类映射(v4 重构后)

> **v4 重构后,Policy 类从 B_model/compose/ 整体迁出,归 G_algo。** 这一节补充说明 Policy 类的来源和去向。

| 新文件(归 G_algo / A_common) | 来源 | 改造点 |
|---|---|---|
| `A_common/types/base_policy.py` | **自创**(v4 阶段引入) | 抽象基类 `BaseVLAPolicy(nn.Module)`,定义 `predict_action(obs_dict, prompt) -> ActionOutput` / `encode_inputs(obs_dict, prompt) -> Dict[str, Tensor]` 接口;`reset()` / `set_normalizer()`;**不含** `compute_loss` |
| `G_algo/PADP/padp_policy.py` | **抄** [diffusion_policy/policy/robomimic/diffusion_unet_hybrid_padp.py:SlidingWindowDiffusionPolicy](../../PADP/diffusion_policy/policy/robomimic/diffusion_unet_hybrid_padp.py) | 248 行整体 `mv`;`@register_policy("padp_unet")`;继承 `A_common.types.base_policy.BaseVLAPolicy`;显式 import `B_model.encoders.VM.robomimic_obs_encoder` 与 `B_model.networks.DM.unet1d_padp`,**实例化**它们;保留 PADP 位置感知 buffer(sliding window + window loss weights) |
| `G_algo/DP/dp_policy.py` | 继承 `PadpUnetPolicy`(共享同一个 UNet 模型类) | `class DpUnetPolicy(PadpUnetPolicy): pass`;`@register_policy("dp_unet")`;**G_algo/DP → G_algo/PADP 跨算法依赖,有意**(同一 model + 不同 algo) |
| `G_algo/common/fusion.py` | 新写 | FiLM / cross-attn / concat 工具 |
| ~~`B_model/compose/`~~(已删除) | — | v4 重构后整体迁出 |

## 9. 数据字段映射(zarr → LeRobot)

| PADP zarr 路径 | LeRobot 字段 | dtype | 备注 |

| `data/obs/agentview_image` | `observation.images.agentview` | uint8 mp4 | mp4 编码省盘 |
| `data/obs/robot0_eye_in_hand_image` | `observation.images.wrist` | uint8 mp4 | |
| `data/obs/robot0_eef_pos` | `observation.state[0:3]` | fp32 | 与 quat / gripper 合并到 state |
| `data/obs/robot0_eef_quat` | `observation.state[3:7]` | fp32 | |
| `data/obs/robot0_gripper_qpos` | `observation.state[7:9]` | fp32 | |
| `data/action` | `action` | fp32 | 维度对齐统一 schema |
| `meta/episode_ends` | `episode_index` + `frame_index` | int | LeRobot 内置切分 |
| (新增) | `task` | str | PADP 没有显式 prompt,迁移时按 task 名填或人工标注 |
