## 二、阶段 1 目标与范围

**核心目标**:在 `square` 仿真任务上,**复现 PADP 当前推理成功率 ≥ 90%**。

**次要目标**:跑通 baseline DP 做对照,确认新架构不引入回归。

**不做的事**:不做真机、不做多 sim 混训、不做其他 VLA、不做 VLM、不做 Flow Matching。

**验收门槛**(三大指标,任一不过则阶段 1 不通过):
1. `square_d0` 单 task 成功率 ≥ 90%(对照 PADP 现状)
2. DP baseline 跑通(差距 ≤ 3% 以确认迁移不引入回归)
3. 7-Layer 检查脚本全部通过(见 [v4 §7](落地方案v4.md#七3-layer-检查清单纠错表))

```python
    """ResNet18 去 fc + Linear 投影到 D_h。
    输入 [B, N_cam, 3, H, W] -> 展平为 [B*N_cam, 3, H, W] -> 投影到 [B*N_cam, D_h]
```

```python
                 horizon: int, num_inference_steps: int = 10,
                 normalizer = None) -> torch.Tensor:
    """DDIM 推理 denoise loop。policy 必须是 register 过的实例。"""
    scheduler = DDIMScheduler(num_train_timesteps=1000, num_inference_steps=num_inference_steps)
    a = torch.randn((encoded["img_tok"].shape[0], horizon, action_dim), device=encoded["img_tok"].device)
    for t in scheduler.timesteps:
        t_batch = torch.full((a.shape[0],), t, device=a.device, dtype=torch.long)
        eps = policy.forward(a, t_batch, encoded)
        a = scheduler.step(eps, t, a).prev_sample
    if normalizer is not None:
        a = normalizer.unnormalize(a, key="action")
    return a
```

**源**:参考 [PADP/diffusion_policy/policy/schedulers.py](PADP/diffusion_policy/policy/schedulers.py) 的 DDIMScheduler
