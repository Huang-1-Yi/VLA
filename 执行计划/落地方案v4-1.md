## 一、阶段 1 目标与范围

**核心目标**:在 `square` 仿真任务上,**复现 PADP 当前推理成功率 ≥ 90%**。

**次要目标**:跑通 baseline DP 做对照,确认新架构不引入回归。

**不做的事**:不做真机、不做多 sim 混训、不做其他 VLA、不做 VLM、不做 Flow Matching。

**阶段 1 启用**:
- 训练:ResNet18 + Conv1d + Sinusoidal + UNet1D PADP(ResNet18 baseline,够用就停)
- 仿真:robomimic(只 square_d0 / can / lift,其他 sim 占位)
- 评估:square_d0 必须跑,can / lift 二选一
- 暂不启用:LM / dinov2 / transformer / 真机 / Flow Matching

**验收门槛**:
1. `square_d0` 单 task 成功率 ≥ 90%
2. DP baseline 跑通(差距 ≤ 3%)
3. 7-Layer 检查脚本全 OK

class PadpUnetPolicy(BaseVLAPolicy):
    """VM(ResNet18) + AM(Conv1d) + TM(Sinusoidal) + state_proj + DM(Unet1DPadp)"""
    def __init__(self, d_h=512, n_obs_steps=2, horizon=16, ...):
        super().__init__()
        self.vm = ResNet18Encoder(d_h=d_h)
        self.am = Conv1dActionEmbedder(d_a=10, d_h=d_h)
        self.tm = SinusoidalTimestepEncoder(d_h=d_h)
        self.state_proj = nn.Linear(14, d_h)
        self.denoiser = Unet1DPadp(d_a=10, d_h=d_h, ...)
    
    def encode_inputs(self, obs_dict, prompt=None):
        """把 obs 编码为 features dict。"""
        img_tok = self.vm(obs_dict["rgb"])  # [B, N, D_h]
        state = self.state_proj(obs_dict["state"])  # [B, D_h]
        return {"img_tok": img_tok, "state": state}
    
    def forward(self, a_t, t, encoded):
        """G_algo.compute_loss 调用:已知 features + noisy action + t,出 denoiser pred。"""
        time_emb = self.tm(t)  # [B, D_h]
        context = {**encoded, "time_emb": time_emb}
        return self.denoiser(a_t, t, context)  # [B, H, D_a]

### 6.1 `G_algo/common/denoise_loop.py`

> **铁律 5 核心体现**:**scheduler 不得在 common 内部硬编码**,由调用方注入。

**关键**:
```python
@torch.no_grad()
def denoise_loop(policy: BaseVLAPolicy, encoded: dict, scheduler,
                 action_dim: int, horizon: int,
                 normalizer=None) -> torch.Tensor:
    """DDIM 推理 denoise loop。policy 必须是 register 过的实例。
    scheduler 由调用方(DP/PADP pipeline.predict_action)注入,本函数不做任何
    scheduler 的实例化。sched 协议:
        - scheduler.timesteps:  可迭代的 long tensor
        - scheduler.step(eps, t, a) -> 输出含 .prev_sample
    """
    a = torch.randn((encoded["img_tok"].shape[0], horizon, action_dim),
                    device=encoded["img_tok"].device)
    for t in scheduler.timesteps:
        t_batch = torch.full((a.shape[0],), t, device=a.device, dtype=torch.long)
        eps = policy.forward(a, t_batch, encoded)
        a = scheduler.step(eps, t, a).prev_sample
    if normalizer is not None:
        a = normalizer.unnormalize(a, key="action")
    return a
```

**关键修正**:本文件**禁止** `from diffusers import DDIMScheduler` 或 `DDIMScheduler(...)` 调用。

**源**:参考 [PADP/diffusion_policy/policy/schedulers.py](../../PADP/diffusion_policy/policy/schedulers.py) 的 DDIMScheduler 协议

### 6.2 `G_algo/DP/dp_pipeline.py`

def compute_loss(policy, batch, horizon=16, num_train_timesteps=1000):
    """无位置加权的标准 diffusion MSE loss。"""
    obs = batch["obs"]
    a0 = batch["action"]  # [B, H, D_a]
    t = torch.randint(0, num_train_timesteps, (a0.shape[0],), device=a0.device)
    noise = torch.randn_like(a0)
    train_sched = DDIMScheduler(num_train_timesteps=num_train_timesteps)  # 训练用 scheduler
    a_t = train_sched.add_noise(a0, noise, t)
    encoded = policy.encode_inputs(obs)
    pred = policy.forward(a_t, t, encoded)
    return F.mse_loss(pred, noise)

def predict_action(policy, obs_dict, horizon=16, num_inference_steps=10, normalizer=None):
    """DP 专用 inference: 实例化自己的 scheduler,传入 common loop。"""
    encoded = policy.encode_inputs(obs_dict)
    infer_sched = DDIMScheduler(
        num_train_timesteps=1000,
        num_inference_steps=num_inference_steps,
    )  # DP 专用调度策略
    return common.denoise_loop(
        policy=policy,
        encoded=encoded,
        scheduler=infer_sched,                      # 注入!
        action_dim=obs_dict["action"].shape[-1],
        horizon=horizon,
        normalizer=normalizer,
    )
```

from diffusers import DDIMScheduler

def compute_loss(policy, batch, horizon=16, decay="exp", alpha=0.5, num_train_timesteps=1000):
    """per-position weighted MSE loss。"""
    obs = batch["obs"]
    a0 = batch["action"]
    t = torch.randint(0, num_train_timesteps, (a0.shape[0],), device=a0.device)
    noise = torch.randn_like(a0)
    train_sched = DDIMScheduler(num_train_timesteps=num_train_timesteps)
    a_t = train_sched.add_noise(a0, noise, t)
    encoded = policy.encode_inputs(obs)
    pred = policy.forward(a_t, t, encoded)
    w = loss_weights.padp_loss_weights(horizon, decay, alpha)  # [H]
    return ((pred - noise) ** 2 * w[None, :, None]).mean()

def predict_action(policy, obs_dict, horizon=16, num_inference_steps=10, normalizer=None,
                   eta=0.0, beta_schedule="squaredcos_cap_v2"):
    """PADP 专用 inference: 实例化自己的 scheduler(可与 DP 不同参数),传入 common loop。"""
    encoded = policy.encode_inputs(obs_dict)
    infer_sched = DDIMScheduler(
        num_train_timesteps=1000,
        num_inference_steps=num_inference_steps,
        eta=eta,                                     # PADP 专用超参
        beta_schedule=beta_schedule,                # PADP 专用超参
    )
    return common.denoise_loop(
        policy=policy,
        encoded=encoded,
        scheduler=infer_sched,                      # 注入!与 DP 的 scheduler 可不同
        action_dim=obs_dict["action"].shape[-1],
        horizon=horizon,
        normalizer=normalizer,
    )
```

def per_position_mse(pred: torch.Tensor, target: torch.Tensor) -> torch.Tensor:
    """返回 [H] shape,每位置 MSE。"""

### 7.1 `C_sim/robomimic/zarr_dataset.py`

> **铁律 6 体现**:本类严格遵守 `BaseVLADataset` 的时序契约 —— 显式接收 `n_obs_steps` / `horizon` 并存为类属性,返回的 `action` 严格对齐 `[self.horizon, D_a]`,**首尾 padding 在本类内处理**。

**关键**:
```python
class RobomimicZarrDataset(BaseVLADataset):
    """读 PADP zarr replay buffer,产出 (obs_dict, action) 二元组。
    obs_dict: {"rgb": {"agentview": Tensor, "eye_in_hand": Tensor}, "state": Tensor}
    action:   Tensor[self.horizon, D_a]  严格对齐
    """
    def __init__(self, zarr_path: str, horizon: int = 16, n_obs_steps: int = 2,
                 pad_strategy: str = "edge_repeat"):  # ← 铁律 6: padding 策略
        # === 铁律 6: 显式存类属性 ===
        self.horizon: int = horizon
        self.n_obs_steps: int = n_obs_steps
        self.pad_strategy: str = pad_strategy
        # ===================================
        self.buffer = ReplayBuffer.copy_from_path(zarr_path)  # 抄 PADP
        self.sampler = SequenceSampler(
            replay_buffer=self.buffer,
            sequence_length=horizon,
            pad_before=n_obs_steps - 1,      # ← 头 padding
            pad_after=horizon - 1,          # ← 尾 padding
            pad_strategy=pad_strategy,      # 'edge_repeat' / 'zero'
            get_pad_mask=False,
        )  # 抄 PADP

    def __getitem__(self, idx: int) -> tuple[dict, torch.Tensor]:
        """派生类:严格返回 [self.horizon, D_a]。"""
        sample = self.sampler.sample_sequence(idx)
        obs_dict = self._extract_obs(sample)        # dict 形态
        action = torch.from_numpy(sample["action"])  # [self.horizon, D_a]
        return obs_dict, action

    def _extract_obs(self, sample: dict) -> dict:
        """抽取最近 n_obs_steps 帧作为 obs window。"""
        return {
            "rgb": {
                "agentview": torch.from_numpy(sample["obs"]["agentview_image"][-self.n_obs_steps:]),
                "eye_in_hand": torch.from_numpy(sample["obs"]["robot0_eye_in_hand_image"][-self.n_obs_steps:]),
            },
            "state": torch.from_numpy(sample["obs"]["robot0_eef_pos"][-self.n_obs_steps:]),  # [n_obs_steps, D_s]
        }
```

**首尾 padding 说明**(铁律 6 关键实现):
- **头 padding**(`pad_before=n_obs_steps-1`):让首帧也能采到 `n_obs_steps` 长度的历史 obs;策略为 `edge_repeat`(用首帧重复填充)
- **尾 padding**(`pad_after=horizon-1`):让尾帧也能采到 `horizon` 长度的未来 action;策略为 `edge_repeat`(用尾帧重复填充)
- `get_pad_mask=False`:不在 batch 里返 padding mask(由下游 G_algo 决定是否需要)
- **基类不变性**:本类的 `__getitem__` 返回的 action shape 永远是 `[self.horizon, D_a]`,**调用方不需要关心 padding**

**源**:抄 [PADP/diffusion_policy/dataset/robomimic/replay_image_dataset_padp.py](../../PADP/diffusion_policy/dataset/robomimic/replay_image_dataset_padp.py) 的 sampler 逻辑 + SequenceSampler 的 pad_* 参数
